- Swimlane and card template setups for clear process visualization
- Analytics and cycle-time reporting presets for continuous improvement
- Integration guides covering Slack, Jira, GitHub and email
- Step-by-step tutorials covering boards, workflows, and permissions
- Real-world examples demonstrating efficient lean workflow and Kanban management

- Windows 10/11 (web app)
- Active Kanbanize account (Free or Paid)

## Usage

Open the extracted folder and explore the template and guide directories. Import the included Kanban board templates into your Kanbanize workspace or follow the documentation to configure workflows, WIP limits, automations and analytics. The guides provide practical instructions for each resource.
